# 本土化中英文模型实验（2026-10-10）

本轮完成样例收集、独立双语训练、KMP 字段归一化与开发评估。**模型仍是实验候选，没有发布，也没有替换 APP 的 v1.1 中文模型。** 全部最终 test 为空；没有独立人工盲测或三端真机性能证据。

## 数据与来源

中文合成 train 10,136 / dev 900；英文合成 train 10,137 / dev 900；另有中文 34 / 英文 38 条助手编写挑战。它们都不是经过人工复核的真实用户分布。根目录旧 35 条开发挑战保留。首次生成后的语言 dev 固定，第二轮不重划测试集。

另导入 [Amazon MASSIVE 1.1](https://github.com/alexa/massive) 的中文与英文原始 train/dev，各 13,547 条，共 27,094 条；其中各 4,011 条进入复核队列。原始来源分区、意图、槽位、平行组及 CC BY 4.0 署名保留。官方 test 各 2,974 条未导入。**公开语料没有用于当前权重，也没有把原始槽位冒充 Deadliner 完整提案真值。** 详情见 `data/sources/massive/import-report.json` 和 NOTICE。

后续标注需人工判定是否应添加，补全 kind/title/date/schedule/note，与固定 now/timezone 一起存储；平行组保持同一分区，避免跨语言泄漏。最终测试由独立审核冻结，不能把当前 dev 拆出来重新命名。

## 表达政策与共享代码

中文覆盖转钟/轉鐘、今儿/明儿/明兒、明早/明晚、晌午配明确钟点、下晌、差一刻/差十分、半/刻、礼拜、天天及周期计数。按用户约定转钟=当日24:00=次日00:00；跨月跨年采用日历日期运算。周一24:00习惯提醒对应周二00:00，需要旋转星期掩码。“转钟后”不能精确成午夜。

英文独立训练和归一化：today/tomorrow/next weekday、AM/PM、12am/12pm、noon/midday、tonight at midnight、quarter past/after/to、half past、带时段语境的英国 half seven、weekdays/weekends、once/twice/three times a week。midnight tomorrow、缺少上下文的 half seven、EOD/COB、03/04、every other day/fortnightly 等有歧义或不能表示的输入应继续确认。

模型预测意图及字符槽位，KMP 仅归一化提取的 TIME/REPEAT；不会重新把标题中的 tomorrow/明天当日期。允许日期和钟点被标题隔开；仅清理时间/周期分隔逗号，不删除标题内部标点。未归入槽位的非中性文本会拒绝解码，避免遗漏“后/after/not”还输出精确提案。manifest 新增 codec.locale，旧清单默认 zh。

这没有完成三端按语言选择/下载模型、原生 UI i18n 或回退策略更改。生产 QuickAddLocalRecognizer 仍然 model ?: rules；三个 UI 对非 ready 结果的采用也需单独验收。
