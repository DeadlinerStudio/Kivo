# 中文 TASK/HABIT 联合工程筛查语料 v3

本目录全部为合成数据，未经独立人工审核，不是正式准确率或发布证据。来源、条数和冻结 SHA256 以 `provenance.json` 为准；本轮运行结果见 [原型报告](../../docs/task-habit-joint-prototype-v3.md)。

| 分区 | 原文数 | 用途 |
| --- | ---: | --- |
| train | 20,000 | 共享编码器、意图与片段头 |
| rank | 4,000 | 学习式重排对照；当前选中方案未使用 |
| quality | 6,000 | 冻结编码器后的实际提案正确性评分 |
| dev | 2,000 | 检查点、架构和重排消融选择 |
| cal_fit | 2,000 | 正确性评分的独立单调校准 |
| cal_gate | 4,000 | 两类型共12档阈值搜索与风险筛查 |
| test | 4,000 | 冻结冠军与阈值后的业务评估 |
| protection | 2,000 | 不支持/确认场景保护评估 |

前七个分区均为 TASK/HABIT/CONFIRM=40/40/20；protection 全部要求确认。每个分区及跨分区原文源组不重复，完整标题和地点实体隔离；**生成句式仍共享，不是表达家族盲测**。有限实体与模板使结果偏乐观，不能把逐行统计上界推广到真实用户分布。

角色为 `TITLE/TIME/LOCATION/NOTE/CONNECTOR/DAYS/GOAL_WINDOW/COUNT`，位置为原文 Unicode `[start,end)`；不使用旧九类 BIO 监督入口。金标时间/星期/目标由生成器独立编写，Core金标路径检查只验证业务契约，不替换金标。

v3训练集回放旧训练语料及已曝光例子。`regression.jsonl` 是14条已知开发回归，已进入训练，不计独立准确率。旧数据与 v2失败记录保留，未改写历史金标。

本轮主候选已打开校准与最终测试。后续迭代不得重新把这些分区当作未曝光留出；新方案需要另行冻结验证分区。生成入口 `quickadd_training.joint_data --revision 3` 只允许新输出目录，不能覆盖本目录。
